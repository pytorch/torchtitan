What changes between the two dispatchers?

1

Counts are control data

Counts describe how many routed rows cross each source-destination edge. Standard c10d consumes CPU split lists; MinimalAsyncEP keeps the count matrix and row offsets on GPU.

2

A token becomes K rows

Top-K routing duplicates a hidden vector once per selected expert. Six source tokens become twelve routed rows, then return to six token rows through a weighted Top-K reduction.

3

Capacity is not traffic

MinimalAsyncEP reserves R_max rows for safety but only remote-writes the active rows. The unused tail costs memory, not necessarily network bandwidth or expert compute.
