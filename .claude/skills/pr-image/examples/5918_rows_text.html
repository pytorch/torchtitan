SGLang rollout groups reuse the first sample's prompt KV

Each bar is one 1,024-token prompt, for a rollout group of 16 samples that arrive together.
prompt tokens computed read from SGLang's radix cache held back, outside SGLang's queue
Before: all 16 samples go into one prefill batch.
This PR, for softmax-attention models: the first sample prefills alone, and the other 15 wait.
Samples wait when they share this key:
key = (req.priority, req.cache_salt, tuple(req.origin_input_ids))
1,024 prompt tokens computed, plus one page per held sample
So s1-s15 read all but the last page of the prompt from the cache.
On Qwen3-4B-Base with 1 GB300 and 1K prompts, 93.7% of prompt tokens come from the cache, against 0% before and 82.0% on vLLM.
With 4K prompts, the share rises from 59.0% to 93.7%.
Held samples start later, but with 1K prompts the median time to first token drops from 0.46 s to 0.10 s.
